# geprekceria
Ayam Geprek Ceria - Web Pemesanan Online Interaktif

Sistem katalog interaktif dan pemesanan online berbasis web untuk UMKM kuliner Ayam Geprek Ceria.

1. Judul & Deskripsi

Nama Produk Digital: Website Pemesanan Online Ayam Geprek Ceria

Latar Belakang Masalah: Usaha kuliner skala UMKM seringkali menghadapi kendala dalam menyajikan katalog menu interaktif dan menerima pesanan secara terstruktur tanpa bergantung pada platform pihak ketiga dengan biaya komisi tinggi. Website ini hadir sebagai solusi digital independen yang ramah pengguna untuk memudahkan proses pemesanan dari pelanggan langsung ke kasir/admin toko.

Target Pengguna: Pelanggan pecinta kuliner pedas, mahasiswa, pekerja kantor, dan masyarakat umum yang ingin memesan makanan dengan praktis melalui smartphone maupun PC.

2. Teknologi yang Digunakan

Bahasa Pemrograman: HTML5, CSS3, Vanilla JavaScript (ES6+)

Framework / Pustaka CSS: Tailwind CSS (via CDN)

Pustaka Pendukung: Font Awesome v6 (Ikon), Google Fonts - Plus Jakarta Sans (Tipografi)

Platform Publikasi & Hosting: GitHub Pages / Vercel

3. Pemanfaatan AI (AI Usage Disclosure)

Alat AI yang Digunakan: Gemini (Google AI)

Contoh Perintah (Prompt) Utama:

"Buatkan single-file HTML website Ayam Geprek Ceria menggunakan Tailwind CSS dan Vanilla JavaScript yang mencakup navbar, hero section, katalog menu dengan pilihan level pedas, dan drawer keranjang belanja."

"Bagaimana cara mengubah isi array cart JavaScript menjadi format string URL WhatsApp (wa.me) yang rapi dengan encodeURIComponent agar pesan yang terkirim tidak error?"

Penyesuaian / Perbaikan Mandiri:

Menyesuaikan skema warna Tailwind CSS dengan identitas visual Ayam Geprek Ceria (merah cabai dan kuning emas).

Menambahkan fitur pemilihan opsi kustomisasi item (level pedas 0–5 dan varian sambal).

Menyusun dan merapikan struktur pesan teks otomatis yang dikirimkan ke WhatsApp admin agar mencakup detail produk, opsi pedas, total harga, dan format alamat pemesan.
